QUESTÃO 19
--------------------------------------------------------------
Analise o seguinte trecho de código e responda as perguntas:

  @Entity
  public class Funcionario {

      @Id
      private Long id;

      private String nome;
      private String email;
      private String senha;
      private Double salario;
      private String departamento;
  }

  @RestController
  @RequestMapping("/funcionarios")
  public class FuncionarioController {

      @Autowired
      private FuncionarioService service;

      @GetMapping("/{id}")
      public Funcionario buscar(@PathVariable Long id) {
          return service.buscar(id);
      }

      @PostMapping
      public Funcionario criar(@RequestBody Funcionario funcionario) {
          return service.criar(funcionario);
      }
  }

a) Quais problemas de segurança e design existem nesse código?
b) O campo "senha" está sendo exposto na resposta da API.
   Como o uso de DTOs resolveria esse problema?
c) A chave primária não possui geração automática de valor.
   Qual anotação está faltando e qual estratégia você usaria?
d) O campo "email" não tem nenhuma validação. Reescreva a
   classe como um DTO adequado, com as anotações corretas
   de validação para todos os campos que julgar necessário.
e) A injeção no Controller está feita por campo. Reescreva
   o Controller aplicando a melhor prática de injeção.
